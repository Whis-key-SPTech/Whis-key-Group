 # Whiskey

    A Whis{key} propõe a solução de realizar o monitoramento dos níveis de temperatura e umidade nas destilarias de whisky, fornecendo ao nosso cliente dados precisos para uma melhor tomada de decisão.
    
    Com apoio do sensor DHT11 (sensor de temperatura e umidade), que vão capturar os valores dessas medidas para o monitoramento do processo de maturação do whisky e serão exibidas na dashboard, onde é necessario que a temperatura e a umidade do barril siga as métricas ideais para a melhor estado e teór alcólico possível do whisky, de acordo com o tipo de whisky produz.

    Com o sensor DHT11 (Sensor de Temperatura e Umidade), serão coletados os dados que auxiliarão nosso cliente no processo de monitoramento,    durante o período de maturação do uísque. Esses dados serão concentrados em um banco de dados para uma futura análise em nossa dashboard.
